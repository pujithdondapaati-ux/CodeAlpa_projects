# CodeAlpha Stock Portfolio Tracker

A simple Python program that tracks a user’s stock portfolio and calculates the total investment value using hardcoded stock prices.

## Internship Details

- **Organization:** CodeAlpha  
- **Domain:** Python Programming  
- **Task:** Task 2 – Stock Portfolio Tracker  

## Features

- User enters stock names and quantities.
- Uses a hardcoded dictionary for stock prices, e.g. `{"AAPL": 180, "TSLA": 250}`.
- Displays:
  - Per-stock investment value
  - Total portfolio value
- Optionally saves a formatted report to `outputs/portfolio_report.txt`.

## Key Concepts Used

- Dictionaries
- User input/output
- Basic arithmetic
- File handling (writing `.txt` reports)

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/CodeAlpha_StockPortfolioTracker.git
   cd CodeAlpha_StockPortfolioTracker
   ```

2. Run the script:
   ```bash
   python stock_portfolio_tracker.py
   ```

3. Follow the prompts to enter stocks and quantities.

4. When asked, type `y` to save the report to `outputs/portfolio_report.txt`.
